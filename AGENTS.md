# Project Instructions

Before making project changes, consult the relevant reference documents in `.agent/`. These documents are project context and design guidance; read only the files relevant to the current task.

## Reference documents

- `Drwashbusiness.md`: Dr Wash Laundry business details, services, pricing, and website requirements.
- `brandkit.md`: brand-kit image generation guidance.
- `brutalist-skill.md`, `minimalist-skill.md`, `soft-skill.md`, `taste-skill.md`, and `taste-skill-v1.md`: visual design directions. Choose only the direction requested by the task; do not combine conflicting styles.
- `gpt-tasteskill.md`: frontend design and motion guidance.
- `image-to-code-skill.md`: image-led website design and implementation guidance.
- `imagegen-frontend-mobile.md` and `imagegen-frontend-web.md`: image-generation guidance for mobile and web interfaces.
- `redesign-skill.md`: redesign workflow and guidance.
- `output-skill.md`: output and deliverable requirements.

Treat these files as supporting context, not as permission to ignore the user's current request or the existing project's implementation and conventions. When a task clearly invokes one of these directions, read that specific document before acting.
